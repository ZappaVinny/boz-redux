# BOZ Redux branding

The approved BOZ Redux brand, as the client uses it. Colours: black `#0d0e10`, red `#e31c29`,
off-white `#e9eaeb` (the full set is in `include/branding.h`).

| File | Use |
| --- | --- |
| `boz-redux.ico` | Windows icon of every executable (16 to 256 px) |
| `icons/boz-redux-<size>.png` | The icon at 16, 32, 48, 64, 180, 192, 256 and 1024 px; 256 is the window icon and the Linux package icon |
| `boz-redux-logo.png` | The primary logo on a transparent background (the launcher header) |
| `boz-redux-mark.svg`, `boz-redux-mark.png` | The Z mark alone |
| `fonts/` | Barlow and Barlow Condensed (SIL Open Font License, `fonts/OFL.txt`): the launcher and overlay type |

The logo's grey background haze from the source file is removed in this copy.
